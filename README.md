# ScriptureFlow Downloads

Official Windows releases of ScriptureFlow by NID SYSTEMS (PTY) LTD.

ScriptureFlow installs in Demo Mode. A purchased licence removes the
Demo watermark on one activated presentation computer.

## Windows publisher notice

Current preview installers are not yet Authenticode-signed and Windows
may display an Unknown Publisher or SmartScreen warning.

Verify the SHA-256 checksum supplied with each release before installation.
