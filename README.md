# ScriptureFlow Downloads

Official Windows releases of ScriptureFlow by NID SYSTEMS (PTY) LTD.

ScriptureFlow installs in Demo Mode. A purchased licence removes the
Demo watermark on one authorized presentation computer.

## Windows publisher notice

Current preview installers are not yet Authenticode-signed. Windows may
display an Unknown Publisher or SmartScreen warning.

Download installers only from this repository or the official
ScriptureFlow website. Verify the SHA-256 checksum supplied with each
release.
